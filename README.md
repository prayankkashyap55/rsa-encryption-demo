# RSA Encryption Demo

This is a simple Python program that demonstrates how to use RSA encryption and decryption.

## Features
- Generate RSA public and private keys
- Encrypt a message using the public key
- Decrypt the message using the private key

## Requirements
- Python 3.x
- rsa library (`pip install rsa`)

## How to run
1. Clone the repository:
```bash
git clone https://github.com/prayankkashyap55/rsa-encryption-demo.git

Step 2: Install required library
pip install rsa

Step 3: Run the program
python rsa_demo.py
